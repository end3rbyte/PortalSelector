# PortalSelector

PortalSelector lets you name your portals and choose where they lead.

## Controls

- **E:** Rename a portal. Names must be unique among portals in your list and can contain up to 50 characters.
- **Shift + E:** Choose a known destination.

## Features

- No server install required. Players without the mod keep vanilla portal links.
- Players with the mod share portal names and destinations.
- Name portals and choose destinations without matching their names.
- Browse known portals by biome, then by distance from the map center.
- Import vanilla portal links on discovery.
- Build fewer portals by reusing them. A wooden portal costs **40 fine wood, 20 greydwarf eyes, and 4 surtling cores** for balance.
