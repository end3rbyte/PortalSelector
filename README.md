# PortalSelector

PortalSelector lets you name your portals and choose where they lead. The server does not need the mod. Players without it can join the same world and use Valheim's original portal names and connections. Players with the mod share PortalSelector names and destinations.

## Controls

- **E:** Rename a portal. Names must be unique and can contain up to 50 characters.
- **Shift + E:** Choose a known destination.

## Features

- Give each portal a name and connect it to a destination without matching names.
- Browse portals you have discovered, grouped by biome and sorted by distance from the map center.
- Keep a separate list of discovered portals for each character and world.
- Share portal names and chosen destinations with other players using PortalSelector.
- Recognize existing Valheim portal names and connections as you discover them.
- You can reuse portals for different destinations, so you usually need fewer of them. To balance this, the classic wooden portal costs **40 fine wood, 20 greydwarf eyes, and 4 surtling cores** with the mod.
